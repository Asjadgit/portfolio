## 🛠️ Built With

This site uses React, Vite and Tailwind CSS. The contact form posts to a serverless function in `api/contact.js` that sends mail through Gmail.

```bash
npm install
npm run dev
```

To make the contact form work, copy `.env.example` to `.env` and fill in `GMAIL_USER`, `GMAIL_APP_PASSWORD` and `CONTACT_EMAIL`.
